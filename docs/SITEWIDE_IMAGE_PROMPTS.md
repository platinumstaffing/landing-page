# Sitewide Image Direction

## Purpose

This guide extends the documentary visual system from the homepage across the remaining
marketing pages. The goal is a generous, credible image rhythm that helps visitors understand
real work, hiring decisions, career support, and the industries Platinum serves.

Final assets should live under:

```text
public/brand/pages/
  about/
  employers/
  industries/
  job-seekers/
  jobs/
  contact/
  resources/
```

## Shared production rules

- Photorealistic documentary workplace photography with natural, observational moments.
- Tri-state workplace context where it can be shown honestly through climate, architecture, or
  industrial character. Do not insert readable state signage unless the location is real.
- Representative diversity across the complete library, without tokenized casting.
- Accurate PPE, safe equipment use, plausible work zones, and realistic operational details.
- Slightly cool neutral color grade, controlled contrast, natural skin tones, and fine detail.
- Use real overhead, window, or daylight illumination. No cinematic fog, bloom, neon, or glow.
- No subjects posing for the camera. Favor concentration, conversation, movement, and process.
- No third-party logos, readable company names, license plates, confidential records, or screens
  containing legible information.
- No embedded typography. Section headings and captions remain live HTML.
- No fabricated client relationship, branded uniform, award, certification, or recognizable
  executive identity.
- Generate each composition at its requested aspect ratio. Keep the important action inside the
  stated focal region and preserve negative space where noted.

## Shared negative prompt

> Stock-photo handshake, camera-facing group smile, staged boardroom, fake celebration,
> transparent interface, floating chart, futuristic robot, neon lighting, cinematic fog,
> dramatic sparks, unsafe PPE, distorted hands, duplicate people, plastic skin, excessive bokeh,
> artificial HDR, visible logo, readable private data, watermark, caption, embedded text.

## Recommended implementation order

1. Generate and connect the seven page heroes first. They create the largest improvement and can
   use one shared image-enabled `EditorialPageHero` interface.
2. Add form companion images for Job Seekers and Contact. These sections currently contain large
   uninterrupted form surfaces and benefit from a human anchor.
3. Replace solution and industry card grids with indexed editorial rows that can accept the 4:3
   service and industry imagery.
4. Add About story, mission, values, and culture photography.
5. Add Resources category thumbnails after real articles begin replacing the current
   articles-in-progress state.
6. Add Search Jobs supporting imagery last. Job search controls and actual listings must remain
   the dominant interface.

## Loading and accessibility notes

- Page hero images should use `priority` and accurate `sizes`.
- All below-fold images should lazy-load through Next Image defaults.
- Reserve dimensions using the exact aspect ratios above to avoid layout shifts.
- Use `object-cover` only after every asset has been generated at its final requested ratio.
- Use the listed focal points to protect faces and operational details at responsive crops.
- Keep copy on opaque surfaces. Do not place long text directly over busy workplace imagery.
- Meaningful photographs use the provided alt-text drafts. Purely atmospheric duplicates should
  use empty alt text.
- Do not repeat the same photograph twice on one page.

Until dedicated files exist for C03, C04, R02–R05, and R07, those slots reuse an existing
photograph with a matching scene (`src/content/page-images.ts` `reusedPageImages`). Replace the
aliases with the generated files when they arrive.
